# README 视觉素材：GIF 与替代方案

> 官方仓库和市场索引都吃动图。理想素材是「打字 → 切走 → 切回 → 字还在」，三秒看完。
> 真 GIF 需要人在 GUI 上录屏，本轮先交付一个可用的静图替代品，并把录制脚本写好。

---

## 方案 A：三帧静图（**已交付**）

`assets/flow.png` · 1200×430 · 白底浅灰卡片风格

三帧横向排列，中间两个箭头：

| 帧 | 画面 | 想让人看到的东西 |
|---|---|---|
| ① 新建会话 · 打字 | 对话窗口 + 输入框里的「明天下午三点评审」+ 蓝色光标 | 字确实敲进去了 |
| ② 切到插件页 | 设置页 tab（对话 / 插件）+ 插件卡片「已保存草稿 · 3 条」+ 灰掉的「（对话区已切换走）」 | 输入框这时候不在屏幕上 |
| ③ 切回 · 字还在 | 同一个窗口、同一句话、右上角一个绿色对勾 | 一个字不差地回来了 |

底部一句话收口：「草稿跟会话走：切页、新建会话、强杀重启，回来都还在」。

### 怎么重新生成 / 改文案

图片是脚本画的，不是手搓的 —— 改字重跑即可：

```bash
python scripts/gen-assets.py
```

脚本会一次性产出 `assets/icon-180.png`、`assets/icon-32.png`、`assets/icon-16.png`、
`assets/flow.png`。文字内容在 `build_flow()` 里，配色常量在文件头部 `INK / PAPER / ACCENT` 一组，
改完 `read_image` 看一眼有没有挤行、有没有裁切。

依赖：`pillow`（绘图）+ `resvg-py`（SVG 栅格化；没有则退 `cairosvg`，再没有退 Pillow 手绘同一套几何）。
Windows 上 `cairosvg` 需要系统 libcairo，容易装不上，`pip install resvg-py` 更省事。

> 已知取舍：静图没有「时间」。它证明不了"切回来那一刻字还在"，只能证明"这两个画面是同一个输入框、
> 同一段字"。评审/市场 PR 里够用，正式发布建议还是补真 GIF。

## 方案 B：真 GIF（以后补）

### 录制前准备

1. 装 [ScreenToGif](https://www.screentogif.com/)（Windows 免费，录制/剪辑/压帧一条龙）。
2. 把 DSH 窗口调到固定尺寸再录，否则帧尺寸会抖。建议录制区域 **900×560 左右**，够看清输入框又不至于文件过大。
3. 准备一段 12～20 个字的样本文本，**必须是中文且带一个标点**，比如「明天下午三点评审，记得带上改好的版本」——
   顺带展示全角标点和中文输入法不会出问题。
4. 关闭桌面通知、清干净输入框历史，别让真实草稿入镜。

### 录制脚本（照着走，一次成）

| # | 动作 | 停留 |
|---|---|---|
| 1 | 打开**新会话**，光标在输入框 | 0.3s |
| 2 | 逐字敲入样本文字（不要整段粘贴，粘贴看不到"打字"） | 全程 |
| 3 | 停顿，让观众看清 | 0.5s |
| 4 | 点左侧**新建会话**（关键动作，别用快捷键，观众要看鼠标点在"新建会话"上） | 0.3s |
| 5 | 切到**设置 → 插件**页，露一下 dsh-composer-draft-keeper 卡片 | 0.6s |
| 6 | 切回那个会话 | 0.3s |
| 7 | 鼠标停在输入框旁边不动，让"字还在"停留 | **1.0s（最重要，别省）** |

总时长控制在 **4～6 秒**。超过 8 秒没人看完。

### ScreenToGif 参数

- 帧率：**10 fps** 足够（打字动作不需要 30fps），录出来体积能小一半。
- 保存前用内置编辑器砍掉头尾空白帧，再做「减少帧数」。
- 导出：GIF，宽度 **900px**，勾选「循环」。
- 体积目标 **< 2MB**。超了就先减色到 128 色、再砍帧，别降分辨率（降了字就糊）。
- 如果背景是纯色 UI，减色几乎不掉画质，优先走这条路。

### 交付

导出为 `assets/demo.gif`，然后在 `README.md` 里把下面这行的注释对调：

```markdown
<!-- 现在是静图 -->
![](assets/flow.png)

<!-- 真 GIF 版本：
![](assets/demo.gif)
-->
```

换成：

```markdown
<!-- 真 GIF 版本：
![](assets/flow.png)
-->
![](assets/demo.gif)
```

静图别删 —— GIF 加载失败（企业内网、部分镜像站）时还能退回去。

### 验收（录完自己看一眼）

- [ ] 三秒内能看懂在发生什么，不需要读文字说明
- [ ] "新建会话"那一下点得清楚，不然观众以为是刷新页面
- [ ] 切回后输入框里的字**逐字对得上**样本文字，没有少字、没有多光标
- [ ] 文件 < 2MB，GitHub 页面上不用点开就能自动播
- [ ] 首帧不是空白（有些客户端拿首帧当封面）

## 图标

`assets/icon.svg`（矢量源）+ `assets/icon-180.png`（180×180）+ `icon-32.png` / `icon-16.png`。

意象：一张草稿纸 + 一枚压在上面的书签 = 「这段字被别住了，跑不掉」。
两色打底（深墨 `#16202E` + 纸白 `#F7F9FC`）加一个强调色（`#3B7BFF`），
圆角 40/180，符合 DSH 插件图标的圆角底板惯例。

要改配色只动 `assets/icon.svg` 里的三个色值，然后重跑 `python scripts/gen-assets.py`。
